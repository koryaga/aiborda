# Ядро на pi SDK: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** заменить собственное ядро агента на pi SDK, дать образу настоящий origin со всем HTML5, а модели — инструменты pi для выхода наружу.

**Architecture:** один процесс Node держит сессию `createAgentSession`, отдаёт оболочку на 8730 и образ на 8731. Модель зовёт `page_exec`, запрос идёт через оболочку в образ по SSE вниз и POST вверх. Изоляция обеспечивается разными origin, а не атрибутом `sandbox`.

**Tech Stack:** Node ≥ 20, ESM, `node:test`, `@earendil-works/pi-coding-agent@0.84.2`, `typebox`. Больше ничего нового.

`docs/superpowers/specs/2026-08-20-pi-core-redesign-design.md`. Расхождения

## Отступление от спецификации, принятое здесь

Спецификация называет WebSocket каналом сервер → образ. **Реализуем SSE вниз и
POST вверх.** Причина: в Node есть WebSocket-клиент, но нет сервера; пакет `ws`
стал бы первой зависимостью помимо pi (сейчас он в дереве только транзитивно,
через jsdom, и опираться на это нельзя). SSE-код у нас уже написан и покрыт
тестами, POST тривиален, а задержка на петле несущественна на фоне генерации
модели. Спецификация правится в задаче 7.

```js
// Мост от сервера к образу. Сервер не достаёт до образа напрямую: запрос
// уходит в оболочку по SSE, оболочка передаёт его образу через postMessage,
// и результат возвращается обратно POST-ом. Здесь живёт только сопоставление
// запросов с ответами.

export function createBridge({ send, timeoutMs = 15000 } = {}) {
  const pending = new Map();
  let seq = 0;
  let sender = send;

  function call(code) {
    if (!sender) return Promise.reject(new Error('оболочка не подключена'));
    const id = 'p' + (++seq);
    return new Promise((resolve, reject) => {
      const timer = setTimeout(() => {
        pending.delete(id);
        reject(new Error(`образ не ответил за ${timeoutMs} мс`));
      }, timeoutMs);
      pending.set(id, { resolve, reject, timer });
      sender({ type: 'page_exec', id, code });
    });
  }

  function deliver(msg) {
    const entry = pending.get(msg?.id);
    if (!entry) return false;          // чужой или повторный ответ
    pending.delete(msg.id);
    clearTimeout(entry.timer);
    entry.resolve(msg.ok
      ? { ok: true, value: msg.value }
      : { ok: false, error: msg.error });
    return true;
  }

  function reset(reason) {
    for (const [, entry] of pending) {
      clearTimeout(entry.timer);
      entry.reject(new Error(reason));
    }
    pending.clear();
  }

  return {
    call, deliver, reset,
    pendingCount: () => pending.size,
    setSender(fn) { sender = fn; },
  };
}
```

```js
import { createAgentSession } from '@earendil-works/pi-coding-agent';
import { Type } from 'typebox';

// Контракт с моделью задаётся штатными средствами pi: promptSnippet и
// promptGuidelines попадают в системный промпт, когда инструмент активен.
// Продуктовая рамка — в AGENTS.md, его pi читает как контекстный файл.
const GUIDELINES = [
  'Страница — единственный интерфейс с человеком. Отвечай не текстом, а изменением DOM: пиши в #out, меняй элементы, создавай новые.',
  'page_exec и читает, и меняет. Читай и меняй в одном вызове, не трать на чтение отдельный шаг.',
  'Состояние интерфейса храни в DOM. Долговременное состояние — в localStorage: он переживает перезагрузку страницы, а DOM нет.',
  'Заметки себе пиши в скрытый #notes.',
  'Правки человека приходят дифом. Снимок страницы тебе не присылают — если нужно состояние, прочитай его через page_exec.',
];

export function createPageTool(callPage) {
  return {
    name: 'page_exec',
    label: 'Страница',
    description:
      'Исполнить JavaScript в странице пользователя и вернуть результат. ' +
      'Единственный способ читать и менять то, что видит человек. ' +
      'Доступен весь DOM и HTML5, включая localStorage.',
    promptSnippet: 'page_exec — читать и менять страницу пользователя',
    promptGuidelines: GUIDELINES,
    parameters: Type.Object({
      code: Type.String({ description: 'JavaScript. Значение из return вернётся тебе.' }),
    }),
    executionMode: 'sequential',
    async execute(toolCallId, params) {
      let r;
      try {
        r = await callPage(params.code);
      } catch (e) {
        return { content: [{ type: 'text', text: 'страница недоступна: ' + e.message }] };
      }
      if (!r.ok) return { content: [{ type: 'text', text: 'ошибка исполнения: ' + r.error }] };
      const text = r.value === undefined
        ? 'выполнено, значение не возвращено'
        : String(r.value);
      return { content: [{ type: 'text', text }] };
    },
  };
}

export async function startSession({ cwd = process.cwd(), callPage } = {}) {
  const { session, modelFallbackMessage } = await createAgentSession({
    cwd,
    customTools: [createPageTool(callPage)],
  });
  return { session, modelFallbackMessage };
}
```

Заменить создание сервера на два. `createApp` получает `imagePort`, а
`listen` поднимает оба:

```js
  const server = createServer(async (req, res) => { /* существующий обработчик оболочки */ });

  // Образ живёт на отдельном порту, и это весь механизм изоляции: другой
  // origin даёт ему localStorage и остальной HTML5, но не даёт достать до
  // оболочки. Атрибут sandbox не используется — он дал бы меньше и хуже.
  const imageServer = createServer(async (req, res) => {
    const url = new URL(req.url, 'http://127.0.0.1');
    const allowed = new Set([`127.0.0.1:${imageServer.address()?.port}`, `localhost:${imageServer.address()?.port}`]);
    if (!allowed.has(String(req.headers.host).toLowerCase())) {
      return json(res, 403, { error: 'недопустимый Host' });
    }
    const path = url.pathname === '/' ? '/image.html' : url.pathname;
    // `root` — уже вычисленная в createApp константа с завершающим слэшем,
    // а не сырой opts.webRoot: на слэше держится проверка startsWith.
    return await serveStatic(res, path, root);
  });
```

```js
    listen(port = 8730, imgPort = 8731) {
      return Promise.all([
        new Promise((resolve, reject) => {
          server.once('error', reject);
          server.listen(port, '127.0.0.1', () => { server.removeListener('error', reject); resolve(); });

    close() {
      return Promise.all([
        new Promise(r => server.close(r)),
        new Promise(r => imageServer.close(r)),
      ]);
    },
    get port() { return server.address()?.port; },
    get imagePort() { return imageServer.address()?.port; },
```

```js
    }
```
